# Live playtest operating notes

This file stores stable human-supplied controls and future client-operation facts so they are not lost to chat compaction.

## ArcheAge controls

- `W`, `A`, `S`, and `D`: directional character movement.
- `F`: interact with the selected or nearby in-game object/NPC.

## Safety and proof

- A live client action requires an assigned task and the matching runtime lease.
- Record the exact character, world, fixture, stimulus, and authoritative server-side result.
- Screenshots are corroborating evidence; native server state owns acceptance.
- Never treat fabricated database/objective mutations as gameplay proof.
- Do not store passwords, access tokens, or other secrets in this repository.
