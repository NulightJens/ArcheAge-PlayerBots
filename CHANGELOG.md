# Changelog

## 0.2.0-alpha.7 — 2026-09-14 · Preview

- Separate the server bot core from optional real-client control and observers.
- Improve equipment consumption, route caching, queue expiry and world/instance checks.
- Improve native party lifecycle, persistence, quest identity and turn-in handling.
- Add native resurrection and quest approach/arrival corrections.
- Provide a core-only host patch and a concise in-game guide for non-agent users.

Quest journeys, difficult terrain and sustained PvP remain experimental. Emergency
interaction teleporting and diagnostic route capture are excluded from this preview.
